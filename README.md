# Electric Vehicle Market Performance & Insights

## Project Overview

The **Electric Vehicle Market Performance & Insights** project uses Tableau to explore electric vehicle data through interactive data visualizations. The dashboard is designed to help users understand vehicle distribution, driving range, battery technology, and vehicle performance characteristics.

The project demonstrates the use of data visualization and business intelligence techniques to turn raw data into meaningful insights.

## Objectives

- Analyze the distribution of electric vehicles by manufacturer.
- Explore electric vehicle driving-range patterns.
- Compare average range across manufacturers and years.
- Understand the distribution of vehicles by battery technology and category.
- Analyze vehicle acceleration characteristics.
- Present key findings through an interactive Tableau dashboard.

## Tools & Technologies

- **Tableau** — Data visualization and dashboard development
- **Microsoft Excel** — Dataset storage and inspection
- **GitHub** — Project version control and documentation

## Dashboard Visualizations

The project contains nine visualizations:

1. **Vehicles by Manufacturer** — Compares vehicle counts across manufacturers.
2. **Vehicle Range Distribution** — Shows the distribution of vehicles across driving-range intervals.
3. **Average Range by Manufacturer** — Compares average driving range by manufacturer.
4. **Vehicles by Year** — Displays vehicle counts by year.
5. **Vehicles by Battery Technology** — Compares vehicle counts across battery technology types.
6. **Average Range by Year** — Examines changes in average range across years.
7. **Vehicle Count by Category** — Compares counts across vehicle categories.
8. **Average Acceleration by Manufacturer** — Compares average acceleration across manufacturers.
9. **Total Vehicles KPI** — Displays the total number of vehicle records analyzed.

*Note: Visualizations depend on the fields available in the source dataset.*

## Dataset

The project uses an electric vehicle dataset containing vehicle identifiers and vehicle characteristics, including range and acceleration. Additional fields are used where available.

The dataset is stored in this repository or packaged with the Tableau workbook, depending on the uploaded files.

## How to Use

1. Clone or download this repository.
2. Open the packaged Tableau workbook (`.twbx`) using Tableau Desktop or a compatible Tableau application.
3. Explore the worksheets and dashboard.
4. Use available filters and interactive controls to investigate the data.

## Project Deliverables

- Tableau workbook
- Electric vehicle dataset
- Interactive dashboard with nine visualizations
- Project documentation

## Conclusion

This project demonstrates how Tableau can be used to explore electric vehicle data and communicate patterns through visual analytics. The dashboard brings together vehicle counts, range comparisons, battery technology, and performance measures in one place.
